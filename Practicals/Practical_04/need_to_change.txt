PRACTICAL 04 - CONFIGURATION VALUES NEEDED FOR USER SETUP
================================================================================

1. MySQL Root Password
   File: src/main/webapp/Request.jsp
   Line: String dbPass = "root";
   Change: Replace "root" with your local MySQL password. If your MySQL has no password, change to "".

   File: src/main/webapp/insert_user.jsp
   Line: String dbPass = "root";
   Change: Replace "root" with your local MySQL password.

2. MySQL Port and Database Name
   File: src/main/webapp/Request.jsp & src/main/webapp/insert_user.jsp
   Line: String url = "jdbc:mysql://localhost:3306/demo_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC";
   Change:
   - If your MySQL uses a port other than 3306 (e.g. 3307), update 3306.
   - If your database name is different, change "demo_db".

3. MySQL User
   File: src/main/webapp/Request.jsp & src/main/webapp/insert_user.jsp
   Line: String dbUser = "root";
   Change: Update if your MySQL user name is not "root".
