This document lists every file and setting you might need to adjust on your
computer (such as MySQL passwords, ports, and credentials).

--------------------------------------------------------------------------------
1. PRACTICAL 01 (JDBC Insertion & Retrieval)
--------------------------------------------------------------------------------
File to change: Practical_01/src/main/java/App.java
- Line: String password = "root";
  Action: Change "root" to your local MySQL password. If you have no password, use "".
- Line: String url = "jdbc:mysql://localhost:3306/mydb?...";
  Action: If your MySQL is on another port, change 3306.
- Database: Run Practical_01/schema.sql in MySQL Workbench to create `mydb`.

3. PRACTICAL 03 (Servlets, Request Details, Sessions, Cookies & Socket Chat)
--------------------------------------------------------------------------------
Files to change:
- Practical_03/src/main/java/com/simple/MainServlet.java
  Line: if ("admin".equals(user) && "1234".equals(pass))
  Action: Default login is username "admin" and password "1234". Change if desired.
- Practical_03/src/main/java/com/chat/ChatServer.java & ChatClient.java
  Line: PORT = 5000;
  Action: Change if port 5000 is occupied or blocked by firewall.
- Practical_03/src/main/java/com/chat/ChatClient.java
  Line: SERVER_HOST = "localhost";
  Action: Change to server IP address if running across two separate PCs.
